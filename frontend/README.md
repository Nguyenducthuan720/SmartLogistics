# Smart Logistics — Frontend

Giao diện React + Vite cho quản lý logistics, tài xế và khách hàng.

Chạy tại thư mục frontend:

```powershell
npm install
npm run dev
```

Backend mặc định ở http://localhost:5000/api, khai báo trong src/services/api.js. Socket dùng cùng backend. Backend cần SQL Server; Python AI chạy riêng ở cổng 5001.

```powershell
npm run build
npm run lint
```

Xem [hướng dẫn chạy](../docs/SETUP.md), [cấu trúc và quy trình](../docs/PROJECT_OVERVIEW.md), [báo cáo hiện trạng](../docs/PROJECT_REVIEW.md).
